Detection Rules & Thresholds

Stored in the MySQL table detection_rules. Saving re-runs the analysis on all stored records.

These are simple rule-based indicators: they count events in the stored logs and compare the count with a number you choose. A flagged event means “a person should look at this” — it is not proof of an attack. Real tools also use time windows, geolocation and threat intelligence; this project deliberately keeps rules simple and explainable.
